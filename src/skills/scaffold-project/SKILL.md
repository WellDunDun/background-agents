# Scaffold Project Skill

Use this skill when the factory creates a new repository or project from an idea.

1. Clarify the product boundary from the prompt and pick the smallest useful first release.
2. Choose the stack only from explicit user preference or strong domain fit.
3. Generate a repository with a runnable app, tests, linting, formatting, and deployment notes.
4. Create a README that states setup, commands, and deployment assumptions.
5. Run the first build or smoke test before creating a checkpoint.

Prefer a working vertical slice over a broad skeleton.
